# スマホプロジェクションマッピング / Smartphone Projection Mapping

スマホだけで、映像を実体物の形に合わせて投影できる Web アプリです。
専用PCや高価なソフトは不要で、スマホ／タブレットをピコプロジェクターや外部モニターにつないで使います。

**使う:** https://naominix.github.io/projection-mapping/
（Chrome / Safari で開いてください。ホーム画面に追加するとアプリのように開けます）

## できること

- 素材（MP4 等の動画・GIF・画像）を複数追加し、サムネイル一覧から切り替え・同時表示
- 素材ごとに四隅のピンをドラッグして透視変形（台形の箱や壁に合わせる）
- 投影モード：UIを消して領域外を黒くし、映像だけを表示（ダブルタップで編集画面に戻る）
- プロジェクト保存：ブラウザ内（IndexedDB）への名前付き保存・自動復元と、ファイル（`.pmproj.json`）への書き出し・読み込みで端末間の移動やバックアップが可能
- 明るさ調整、合わせ込み用グリッド表示

## 使い方

1. 上の URL をスマホ／タブレットのブラウザで開く
2. 「素材を追加」から動画・画像を選ぶ（複数可）
3. 素材を選び、四隅のピンを投影したい形の角に合わせる。複数素材はそれぞれピンを持ち、同時に表示できる
4. 「投影モード」で投影開始。戻るときは画面をダブルタップ

## 注意

- スマホ単体では強い光を出せないため、ピコプロジェクターや外部モニターへの接続が前提です。暗い場所で使うとよく見えます
- iPad Safari ではスリープ防止（Wake Lock）が効かないため、投影中は自動ロックを「なし」にしてください
- 保存データはブラウザごとに分かれます。大事なプロジェクトはファイル書き出しでバックアップしてください
- 大きな動画は端末のメモリや保存容量を使います

## 対象

小学生から大人まで。文化祭や店舗展示、ホームパーティーの演出などに。

単一 HTML ファイル（`index.html`）だけで動作します。
